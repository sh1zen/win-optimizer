# win-optimizer Sponsors & Supporters Data

`sponsors.json` on the `main` branch contains the sponsor and supporter data for
[win-optimizer](https://github.com/sh1zen/win-optimizer).

The application loads this file from:

```text
https://raw.githubusercontent.com/sh1zen/win-optimizer/main/sponsors/sponsors.json
```

Keep the bundled snapshot in `src/WinOptimizer.UI/Assets/Sponsors/sponsors.json`
in sync with this file. Place sponsor logos in `sponsors/logos/` and copy them to
`src/WinOptimizer.UI/Assets/Sponsors/logos/` for offline use.

The lists are initially empty. Add only confirmed sponsors and consenting
supporters of this project.
